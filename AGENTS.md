# Portwhim project workflow

Keep meaningful completed changes in local Git commits after appropriate validation. Use focused commit messages and preserve unrelated user changes. Never publish or push to GitHub unless the user asks.

Do not track node_modules, compiled bundles, packaged executables, caches, or private local settings. Keep source, lockfiles, documentation and brand assets tracked.

Brand: use public/brand/mark.svg as the editable master. The approved reference is docs/brand/approved-reference.png. Preserve the straight corners, centered colon and mint port on the right. Do not replace the approved mark with a generic network icon.
